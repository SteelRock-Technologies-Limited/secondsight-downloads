# SecondSight Downloads

Customer download page for the SecondSight Device Updater (GitHub Pages).

- index.html - the page. Palette and wording follow the plugin's sign-in screen.
- links.json - the four download links + the published build. Edit THIS for a new build; the page never changes.
- sr.png - the SR monogram.

The downloads themselves live in OneDrive (SecondSight-Updater-Downloads); this page only links to them.
