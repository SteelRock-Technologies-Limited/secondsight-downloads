First time on a device

  1. On the device: Settings › About phone / About tablet › Software information, tap Build number seven times. Then Settings › Developer options › USB debugging on.
  2. Plug the device into the computer with a data cable.
  3. Unzip the download and run SecondSight Updater. Both systems warn about software they have not seen before, once: Windows shows "Windows protected your PC": click More info, then Run anyway. Mac shows "Not Opened": go to System Settings › Privacy & Security, scroll to Security and click Open Anyway, then confirm with Touch ID or your password. If Terminal asks to access your Downloads folder, click Allow.
  4. Put your name in and press UPDATE DEVICE. If the phone or tablet then asks to allow USB debugging, tick Always allow from this computer and tap Allow; if the updater has already stopped, run it again. It puts SecondSight ATAK on the device if it is not there, installs the plugin and keeps your settings.
  5. Start ATAK on the device. SecondSight is under Tools › Plugins, and signs in with the account you were given.
